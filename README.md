# Smart-Bin-using-ESP32
An IoT-based Smart Bin powered by ESP32 that automates bin operations and enables real-time status monitoring. It features a desktop application to track bin fill levels, prioritize waste collection, and initiate collection requests for efficient waste management.

1. Hardware components
1	ESP32 Development Board	
2	HC-SR04 Ultrasonic Sensor	2	
3	Servo Motor	
4	16×2 LCD Display with I2C Module	
5	NEO-6M GPS Module	
6	Buzzer	
7	LEDs	
8	Breadboard / Connecting Wires	As required	Circuit connections


2. Software and tools
1. Arduino IDE – Programming the ESP32.
2. Python – Developing the desktop monitoring application.
3. Tkinter – Creating the graphical user interface.
4. Wi-Fi – Sending sensor readings from ESP32 to the desktop application.
5. HTTP and JSON – Transferring waste-level and bin-status data.
6. Google Maps – Viewing the bin's GPS location.
